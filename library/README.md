# The rebuilt library

This is the root of the rebuilt proof library (work-plan item I0.3). The
first library is kept in [`archive/first-library/`](../archive/first-library/)
as a reference, not relied on: where this library implements a part of it,
that part is removed from the archive and its dependents import the library
instead. Its results are catalogued in English in
[`docs/library-results.md`](../docs/library-results.md), which the rebuild
follows.

- Modules here take precedence over archive modules of the same name, in the
  command-line checker, the proof workspace and the language reference.
- Each module has one theme, and general helpers are shared across modules.
  The notation module keeps its single-glyph digit map local so parsing
  does not load full-magnitude conversion proofs.
- Every module is listed in `libraryModules` in
  [`web/cubist/modules.mjs`](../web/cubist/modules.mjs), and
  `tests/library.test.mjs` checks that each checks completely and uses exactly
  the assumptions listed for it there.
- The library is self-contained: a module here imports only modules here
  (`web/module-resolution.mjs`). An archive module may import a library
  module, as many import `unat`.
- Nothing is imported automatically: a module that uses the natural numbers,
  numerals included, imports `nat`.

Public `Nat` is the canonical binary carrier `BNat`. Use `import nat; use nat;`
for decimal or binary literals (`5`, `1_000`, `0b101`), binary arithmetic,
comparison, dependent Peano recursion and coherent strong recursion.
`nat` calls the binary literal reader directly: the magnitude never passes
through unary naturals. Computed values print in decimal from their bits;
unreduced literals retain their spelling, including in mathematical displays.

For structural unary induction, use `import unat; use unat;` and `UNat`.
Its constructors remain `zero` and `succ`; its laws have the `unat_` prefix.
Existing structural clients, lexical digits/offsets, list lengths and h-level
indices use this explicit carrier. The public `Z` and `Q` representations
remain unary until NUM2 completes; `binary_integers` provides the new binary
integer ring and domain laws on `BInt`, and `binary_rationals` instantiates
the shared fraction field over it as `BQ`, while the default migration is built.
Public `Nat` no longer matches on unary constructors;
use `nat_peano` for its dependent zero/successor view. A unary numeral is
qualified as `unat.(n)` outside an identity unary view. Imports re-export their
dependencies, and a later import shadows earlier
short names: even `import nat; import hlevels;` exposes unary `zero` and
`add` through `hlevels`. Import `nat` last to use its binary short names.
Explicit `nat.(...)`, `bnat_*` operations and `nat_peano` remain unambiguous
in either order; this migration does not change import visibility.

Conversion remains explicit: `bnat_unary` supplies both maps and inverse laws,
`bnat_semiring` proves their arithmetic laws, `unat_models` supplies the unary
semiring model without binary dependencies, `bnat_models` supplies the
binary model and their semiring isomorphism, and `bnat_transport` supplies
the universe path and transport laws. `bnat_equality` supplies bitwise equality
and setness, `bnat_order` comparison correctness, `bnat_peano` dependent
zero/successor recursion, and `bnat_recursion` strong recursion and factorial.

| [`bnat_semiring`](bnat_semiring.cubist) | Binary semiring laws, addition and nonzero-factor multiplication cancellation, nontriviality, no zero divisors, and conversion preservation. The arithmetic computes directly on bits; this module does not load the general algebra hierarchy. | None |

| [`bnat_peano`](bnat_peano.cubist) | Dependent advance over binary offsets and the Peano eliminator; its zero equation holds by computation and its successor equation is a checked path for arbitrary dependent families. Homogeneous total-state iteration is used only in the successor proof. | None |
| [`bnat_recursion`](bnat_recursion.cubist) | Binary strict-order decisions and successor decomposition; callbacks for every smaller value, coherent dependent strong recursion and its equation; binary factorial with zero/successor laws. Successful decrease checks keep binary witnesses. | None |
| [`classical_axioms`](classical_axioms.cubist) | The statements of the classical assumptions as types, `ExcludedMiddle(U)` and `AxiomOfChoice(U)`, with checks that `LEM(U)` and `Choice(U)` have them. | `LEM`, `Choice`, `Truncate` |
| [`hlevels`](hlevels.cubist) | Contractible types, propositions and sets in every universe below `UU0`, with `HasLevel(U, n, A)` defined by recursion on `n`, so that `IsSet` is level 1 by conversion. Propositions are sets, levels are cumulative, having a level is a proposition, and a retract, such as a type equivalent to another by an inverse, a function type, a type of pairs, a product or a subtype keeps the level of the types it is made from. Contractible types are closed under the same constructions except subtypes, since a subtype can be empty, and being contractible is a proposition. Negations are propositions (`not_is_prop`), and so is the decision of a proposition (`Decidable`, `decision_is_prop`). A type with decidable equality, such as `UNat`, is a set (Hedberg). | None |
| [`h1_truncation`](h1_truncation.cubist) | The propositional truncation `Trunc(U, A)` as a declared type that computes: `merely`, that it is a proposition, maps between truncations, and elimination into a proposition of any universe below `UU0`. | None |
| [`h1_classical`](h1_classical.cubist) | Excluded middle and choice stated over `Trunc`, as `LEM(Trunc, U)` and `Choice(Trunc, U)` give them; double-negation elimination for propositions, deciding a proposition, and resizing a proposition in `U1` to one in `U0`. | `LEM[h1_truncation.Trunc]`, `Choice[h1_truncation.Trunc]` |
| [`universe_automorphisms`](universe_automorphisms.cubist) | Excluded middle for `U0` holds exactly when there merely is an automorphism of `U0` sending `Unit` to `Void`, for the equivalences of [`contractible_maps`](contractible_maps.cubist), with equal types from [`univalence`](univalence.cubist)'s `glue_path`. Both directions without the truncations use no assumption. | Truncation; `LEM` only in the final corollary |
| [`universe_smallness`](universe_smallness.cubist) | Russell's paradox via well-founded trees: no family `B : A -> U` with `A : U` represents every type in `U` up to equivalence (`no_small_universe_family`). Consequently `IsUSmall(U, U)` implies `Void` (`universe_not_small`), with equality taken in `next(U)`, and no type `X : U` is equivalent to `U` (`universe_not_equivalent_to_type`); `russell` states the latter for `U0`. Works in every universe below `UU0`, without univalence. | None |
| [`contractible_maps`](contractible_maps.cubist) | Equivalences as contractible maps, the form the kernel checks a Glue type's equivalences in: the fiber of a function, a function whose fibers are contractible (`IsContrMap`), the type of such equivalences (`ContrEquiv`), the identity, and the equality of two equivalences with one forward map, since being contractible is a proposition. An equivalence has an inverse with both inverse laws (`equiv_inverse`), and every function with an inverse and both inverse laws is one (`inverse_equiv`, after Cubical Agda's `isoToIsEquiv`). | None |
| [`univalence`](univalence.cubist) | Univalence by Glue, for the equivalences of [`contractible_maps`](contractible_maps.cubist). An equivalence glues a path of types (`glue_path`), and a path of types transports the identity to an equivalence (`idtoequiv`). The two are inverse (`glue_path_idtoequiv`, `idtoequiv_glue_path`), so `idtoequiv` is an equivalence (`univalence`). Forward and reverse Glue-path transport agree with the equivalence maps (`glue_path_transport`, `glue_path_transport_reverse`); an equivalence preserving a binary operation identifies its transport with the target operation (`glue_path_operation`). Along every line of Glue types, unglue is an equivalence (`glue_line_equiv`), and the type of types equivalent to a type is contractible (`equivalent_types_contractible`). The `ua` builtin takes the `Equiv` of `import paths_;` instead. | None |
| [`propositions`](propositions.cubist) | The propositions of a universe as a type one universe up, `Prop(U)`. Propositions that imply each other are equal (`prop_ext`, by [`univalence`](univalence.cubist)'s `glue_path`), and equal as propositions (`prop_path`). The equivalences and the paths into a proposition are propositions, so the propositions form a set (`prop_type_is_set`), which `hlevel` uses as a registered rule. | None |
| [`finite_sets`](finite_sets.cubist) | `Fin(n)`, the natural numbers strictly below `n`, with checked setness. Uses public binary `Nat`. | None |
| [`binary`](binary.cubist) | `Binary := Fin(2)`, its values `False` and `True`, and computable Boolean operations `Not`, `And`, `Or`, `Xor` and `Nor`. | None |
| [`powersets`](powersets.cubist) | Generic proposition-valued `PowerSet(U, A) : next(U)` and binary `DecidablePowerSet(U, A) : U`, using `Binary` for characteristic functions, with checked setness of both. No identification between full and decidable powersets is assumed. | None |
| [`continuum_hypothesis`](continuum_hypothesis.cubist) | Universe-indexed CH and GCH over full powersets, with stronger cardinality-dichotomy variants (`DecidableContinuumHypothesis`, `DecidableGeneralizedContinuumHypothesis`); checked implications from each dichotomy to its negative statement and from each GCH to its CH. Infinitude means a mere injection from `Nat`. Generic mere cardinal comparisons, equinumerosity and the separate `CantorContinuumHypothesis` over binary sequences are included. Statements are explicit hypotheses; axiom declarations and the implications to excluded middle and choice remain follow-ups. | None |
| [`lists`](lists.cubist) | Lists of elements of a type in any universe below `UU0`, with their length and concatenation (`append`), whose universe and element type are implicit parameters, read off the lists: `nil` is a unit on both sides, concatenation is associative, and the length of a concatenation is the sum of the lengths. | None |
| [`lexemes`](lexemes.cubist) | Literals' characters (L2.10c): `Glyph`, `Lexeme`, a list of glyphs, and `Parsed(A)`, a parse's value or the position it refuses; `Succeeded`, `parse_answer` and `parsed_value`, by which a literal's term holds `tt` as evidence its parse succeeded; and small parsers, `leading_digits` and `natural_literal`, for notations' literal rules. | None |
| [`quotients`](quotients.cubist) | Set quotients as a declared type: the quotient of a type by a relation, with a class for each element and a path between related classes. It is a set; it has induction into families of sets, of any universe below `UU0`; and a map into a set that respects the relation descends to it, uniquely. No representative is chosen. For an equivalence relation valued in propositions, related elements are exactly those with equal classes (`quotient_effective`, `class_path_equiv`): relatedness to an element descends into [`propositions`](propositions.cubist)' `Prop(U)`. Induction into a family of propositions needs only the classes (`quotient_induction_prop`), and a map of two arguments that respects the relation in each descends (`descend2`). | None |
| [`algebra`](algebra.cubist) | The algebraic hierarchy as [theories](../web/reference/theories.html): `Magma`, `UnitalMagma`, `Semigroup`, `Quasigroup`, `Loop`, `AssociativeQuasigroup`, `Monoid`, `CommMonoid`, `Group` (one inverse implements both quasigroup divisions), `AbelianGroup` (a group and a commutative monoid, sharing their monoid), `Ring` (an abelian group for addition and a monoid for multiplication on one set, with both distributive laws), `CommRing` (a ring with commutative multiplication, deriving right distributivity) and `Field` (a commutative ring with inverses of all but zero, and zero not one), each with its models, homomorphisms and isomorphisms. A ring reads numerals in binary: `of_nat(n : BNat)` doubles from the leading bit, so its work and size grow with the number of bits, and `of_unat(n : UNat)` keeps the unary numeral. A generic numeral prints as `A.(2)`, or bare where `A`'s notation is selected. The natural numbers as a commutative monoid for addition and for multiplication. In any quasigroup, cancellation holds on both sides; in any commutative monoid, products regroup (`mul_left_comm`, `mul_right_comm`, `mul_interchange`); in any group, cancellation on both sides and the uniqueness of inverses; in any commutative ring, `x * zero = zero`, right distributivity and `neg(x) * y = neg(x * y)`. | None |
| [`ring_numerals`](ring_numerals.cubist) | A ring's binary numerals agree with its unary ones (`of_nat_unary`, `of_unat_binary`), and a map from `BNat` that preserves zero, one, addition and multiplication sends each natural to the ring's numeral (`of_nat_map`), as `bint_of_nat` does. | None |
| [`ordered_algebra`](ordered_algebra.cubist) | `OrderedRing` extends `Ring` with a proposition-valued, cotransitive, tight strict order compatible with addition and positive multiplication, including constructive reflection of positive products to apartness of each factor from zero. `OrderedCommRing` extends both `OrderedRing` and `CommRing`; `OrderedField` extends `OrderedCommRing` with inverses of elements apart from zero. Non-strict order is the negation of reverse strict order. `ordered_inv` extracts the unique inverse from its truncated law. Apartness is a truncated positive-or-negative sign, stronger constructively than mere inequality with zero. No decidable order or completeness is assumed; ordered integer/rational models are not yet provided. | None |
| [`differences`](differences.cubist) | The ring of differences of any additively cancellative commutative semiring with decidable equality: the same-difference quotient, its ring operations and laws, decidable equality, an injective semiring embedding, compact zero-decision certificates, and no-zero-divisor laws from multiplicative cancellation and additive trichotomy. Unary and binary integers instantiate this shared construction. | None |
| [`integers`](integers.cubist) | The unary compatibility integers instantiate the shared ring and domain proofs in `differences`: a pair of unary naturals `(a, b)` stands for `a - b`, and pairs with the same difference are one integer, `Z`. Negation, addition and multiplication descend to it; it is a commutative ring (`integers`), with no zero divisors (`int_mul_nonzero`) and zero not one, and its equality is decidable (`int_decide`), through the quotient's effectiveness. Every operation computes on closed integers. | None |
| [`binary_integers`](binary_integers.cubist) | Binary integers `BInt` instantiate `differences` at the binary semiring, as the same-difference quotient of `BNat` pairs, with negation, addition, multiplication, the `binary_integers` commutative-ring model, decidable equality, zero not one, and an injective natural embedding preserving zero, one, addition and multiplication. Decimal and `0b` literals enter binary magnitudes directly. The shared no-zero-divisor proof is instantiated as `bint_mul_nonzero`; `bint_decide_zero` supplies compact nonzero certificates. Computed values remain quotient representatives; the public `Z` migration follows in NUM2. | None |
| [`fractions`](fractions.cubist) | The field of fractions of a commutative ring with decidable equality, no zero divisors and zero not one: fractions `x / d` carry evidence that `d` is nonzero, cross multiplication defines their quotient relation, and their operations descend to a field (`fraction_field`) with a separate equality decision (`q_decide`). The coefficient embedding `q_embed` is injective and preserves zero, one, addition, multiplication and negation. This construction does not import the integer instance. | None |
| [`rationals`](rationals.cubist) | The integers' field of fractions (`rationals`, `Q`), with `rat(a, k)` for `a / (k + 1)`, decidable equality and checked fraction/decimal literals. Arithmetic computes on closed rationals. | None |
| [`binary_rationals`](binary_rationals.cubist) | The shared fraction field over `BInt`, named `BQ`, with decidable equality, inverse, and the checked integer embedding `bq_of_int`. Integer, fraction, decimal and `0b` literals accumulate binary magnitudes; only glyph digits and source offsets are unary. Values remain quotient representatives; their folded normal forms (`!!`) compute, and the full normal forms of their certificates (`!!!`) do not yet (the runtime roadmap's NUM2 section). The public `Q` migration remains NUM2 work. | None |
| [`squares`](squares.cubist) | Squares with named edges (L2.8): `Square(a0_, a1_, a_0, a_1)`, a path from its left edge to its right edge over its bottom and top edges, each edge named by its corners `a00`…`a11`. The reflexive square, the naturality square of a homotopy, transposition and both flips, double composition with its filler (`trans` is its case with a constant first edge), and horizontal and vertical composition, each by conversion. Two squares on the same three sides have equal tops (`top_unique`); so a square is an equation of composites (`square_to_path`), and back (`path_to_square`), and a homotopy's naturality (`naturality_path`) and a map's action on a composite (`cong_trans`) follow. | None |
