Edit native syntax

Definitions refer to the checked source registry by name. Editing does not change that registry.

The checked term as the kernel stores it: an abstract syntax tree of native nodes, typeset above. Each row is one node: its C constructor opcode, payload, and operands. %n are term handles local to this replay session; identical syntax is one node, listed once, so the tree is shared as a graph. Zero marks an unused operand or the end of a list.

Reduce a native occurrence

Choose a root, then follow its operands below. A path selects one occurrence even when several uses share a handle. The AST table links only inspect nodes; unfold a definition with δ before stepping inside its body.

Each operation issues one checked kernel instruction at the selected path. WHNF and Normalize can perform many reductions; Glue can normalize its side conditions. The budget is per instruction and is not automatically increased. Back undoes an accepted operation; Kernel graph shows its derivation.

The checked term's instruction derivation, one THTH-style rule per judgement, including manual native steps. Each judgement lists the judgements it was derived from and those that use it; a step names the subterm it contracts.
