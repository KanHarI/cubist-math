KERNEL REFERENCE · TO BE WRITTEN

The C kernel

The kernel checks every term the elaborator produces. This reference will describe its terms, its native opcodes and how it checks them.

This page is an outline, to be written. Until then, the language reference explains how source becomes kernel terms, and the kernel workbench shows the native term of any checked declaration.

What the kernel does

The kernel is written in C and compiled to WebAssembly for the browser. It stores terms in an arena of native nodes, each an opcode with a payload and up to four operand handles. It accepts a declaration only when its term has its stated type, and it is the only part of Cubist that is trusted.
