Universes

U0 denotes U₀; U1, U2, and U3 denote U₁, U₂, and U₃. In particular U0 : U1. Smaller types can be lifted to larger universes; a larger type cannot be silently lowered.

def large_identity(A : U1, x : A) = x;
def lifted_unit = typed(U1, Unit);
def identity(U : Universe, A : U, x : A) = x;
def small_identity = identity(U0);
def universe_identity = identity(U2, U1, U0);

A declaration with A : U0 remains restricted to small types. Write U : Universe to parameterize a declaration over a universe. This makes the declaration a template: the elaborator makes a separate, specialized copy for each universe it is used at, and the kernel checks that copy. The argument must be a universe, not an arbitrary type. Universe arguments are explicit; the compiler does not infer them. Several universe parameters can be grouped, as in (U V : Universe, A : U, B : V). A family may need an explicit lift, such as fun (a : A) => typed(U1, Unit).

When inspecting a universe template, choose U0, U1, U2, or U3 for each universe parameter. The inspector checks that specialization and shows its expression, type, and local context. Names inside the template use the selected universes too. Workbench transfers preserve the selection and display names such as GroupAt_U0; the generic declaration remains a template.

IsProp(A), IsSet(A), and Equiv(U, A, B) are library definitions, not new sorts or language keywords. In particular, IsSet(A) says that any two identity proofs between the same elements agree.
