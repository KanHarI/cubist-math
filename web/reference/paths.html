Equality and paths

x = y is the identity type, not an instruction to rewrite source text. Its elements are paths. Equality of paths can itself be stated using another identity type. Equality by computation is handled separately by conversion.

Two notions of “equal” appear throughout the reference:

  • Definitional equality (conversion): two terms compute to the same normal form, as 0 + n and n do. The checker uses it silently. It is never a proposition you state or prove.
  • Propositional equality: a path p : x = y, a proof that must be constructed, as for n + 0 = n. Using it to replace x by y requires an explicit operation: transport, cong, rw or simp.
OperationRequired data and result
x =[T] yEquality of two elements of the explicitly supplied carrier T. Plain x = y infers the carrier.
refl(x)A path x = x. It also proves x = y whenever x and y are definitionally equal.
sym(p)Symmetry: reverse p : x =[T] y to obtain y =[T] x, preserving the carrier.
trans(p, q)Compose p : x = y and q : y = z into x = z.
cong(f, p)For a function with constant codomain, map p : x = y to f(x) = f(y).
transport(C, x, y, p, value)Move value : C(x) along p : x = y to obtain C(y). The shorter along C by p from value infers x and y.
apd(f, x, y, p)For a dependent function f : forall x : A, C(x), prove transport(C, x, y, p, f(x)) = f(y). For the direct dependent path, use apd_path(f, p).
path_induction(A, motive, base, x, y, p)Identity elimination, described below. Does not require a classical axiom.

sym, trans, and cong are built into the language and need no import. They construct cubical paths pointwise and add no axiom. The paths library names them inverse, concatenate and similar, and proves their laws, such as trans(p, refl(y)) = p.

def reverse_path(A : U0, x y : A, p : x = y) : y = x {
  exact sym(p);
}

def join_paths(A : U0, x y z : A, p : x = y, q : y = z) : x = z {
  exact trans(p, q);
}

def map_path(A B : U0, f : A -> B, x y : A, p : x = y) : f(x) = f(y) {
  exact cong(f, p);
}

sym also reverses equalities of types: in A =[U] B, the endpoints A and B are types and their carrier is the universe U.

def reverse_type_equality(A : U1, B : U1, p : A =[U1] B) : B =[U1] A {
  exact sym(p);
}

For example, univalence applied to the group structure identity equivalence gives (G =[Group] H) =[U1] GroupIso(G, H). Applying sym gives the orientation used in the highlighted group theorem: GroupIso(G, H) =[U1] (G =[Group] H).

Path induction

The path-induction motive takes x : A, y : A, and p : x = y, and returns a type. The reflexive case base takes a : A and proves motive(a, a, refl(a)). The eliminator returns motive(x, y, p). Informally: to prove something about every path, it suffices to prove it for reflexivity, provided both endpoints are free to vary.

Some inferred pair projections do not retain enough equality information for sym, trans, or cong. Introduce an explicitly typed claim with have p : x = y := term; in that case.

Explicit carriers

x =[T] y is equality with an explicit carrier: both endpoints must have type T. Plain x = y infers that carrier. This is an identity type, not an assertion of definitional equality or a cast.

def explicit_reflexivity(U : Universe, A : U, x : A) : x =[A] x {
  exact refl(x);
}
