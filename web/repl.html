CHECKED ONE ENTRY AT A TIME

REPL

Define names, ask for types and evaluate terms. The kernel checks each entry as a small file that imports the entries before it.

Commands

let x := 7;Define a name. Any declaration of a file works too: def with a proof block, opaque def, simp_rule.
typeof x;The type of a term: Nat.
evaluate x;The value of a term: 7. A term alone is evaluated too.
import naturals;Load a module. naturals provides +, *, < and <=.
helpList the commands.

Enter runs an entry. Shift+Enter adds a line, and so does Enter while a bracket is open, so a proof block can be typed as in a file. ↑ and ↓ recall earlier entries. An entry that does not check changes nothing.

To use the names of a proof, open it in the proof workspace: the console under it has them loaded. The language reference describes every construct, and each of its pages has a REPL bar at the bottom.
